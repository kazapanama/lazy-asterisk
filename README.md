# Астеріск для лінивих

Розширення для Chrome, яке спрощує роботу з Asterisk CLI у веб-інтерфейсі FreePBX. Додає зручні інструменти для керування дзвінками та конференціями без необхідності вводити команди вручну.

## Можливості

*   **Керування конференціями**:
    *   Перегляд списку активних конференцій (`confbridge list`).
    *   Викидання (kick) окремих учасників або всіх учасників конференції одразу.
*   **Керування дзвінками**:
    *   Перегляд активних каналів.
    *   Детальний перегляд із кнопками **hangup** для швидкого завершення конкретного дзвінка.
*   **Автоматизація**:
    *   Режим автоматичного повторення останньої команди кожні 5 секунд (зручно для моніторингу).
*   **Швидкі дії**:
    *   Готові кнопки для популярних команд CLI.

## Встановлення

1.  Завантажте код розширення.
2.  Відкрийте `chrome://extensions/` у браузері Chrome.
3.  Увімкніть "Режим розробника" (Developer mode) у верхньому правому куті.
4.  Натисніть "Завантажити розпаковане розширення" (Load unpacked) та виберіть папку з файлами.

## Використання

Розширення автоматично активується на сторінці командного рядка Asterisk (FreePBX) на будь-якій адресі (`*://*/admin/config.php?display=cli*`).
