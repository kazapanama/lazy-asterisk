Lazy Extension — Візуальні тести

Кожен сценарій відкриває мок-сторінку FreePBX, на яку завантажуються реальні utils.js + main.js. Інтерактивно клікайте кнопки розширення й дивіться, як рендериться UI.

  • 1. Початковий стан Панель розширення вставлена в другий .container-fluid. Жодну команду ще не надіслано — це чистий вигляд після initExtension().
  • 2. Список конференцій (2 активні) Автоклік «Завантажити конференції» → мок відповідає переліком конф 5500/5501 → з'являється dropdown.
  • 3. Список конференцій (порожньо) Мок відповідає «No active conferences» → має з'явитися попередження «Заз немає конференцій :(».
  • 4. Конференція з учасниками Завантажує конф 5500 → у pre[2] з'являються inline-кнопки kick перед кожним SIP-ID + червона «ВИКИНУТИ ВСІХ» внизу.
  • 5. Базовий список дзвінків Автоклік «Показати дзвінки» → core show channels, вивід без кнопок.
  • 6. Детальний список дзвінків з hangup-кнопками Автоклік «Показати дзвінки (детальніше)» → SIP-канали отримують inline-кнопки hangup.
  • 7. Режим повторення interval Автоклік «Відправляти раз в 5 секунд» → лейбл змінюється на «Перестати повторювати», стартує прогресбар-відлік. Кнопками −/+ поряд можна змінювати інтервал (±1с, мінімум 1с) — напис і швидкість бара оновлюються динамічно, навіть під час активного повтору.
  • 8. Підсвітка тексту в виводі У поле «Підсвітити в виводі» вписано «200», натиснуто «Показати дзвінки (детальніше)» → жовтим виділяються всі входження «200» у pre[2], включно з hangup-кнопками.
  • 9. Підсвітка + повтор 5с регресія Це сценарій, заради якого фічу й додали. Підсвітка «200» залишається жовтою навіть після того, як setInterval(5000) перерендерює pre[2] — на відміну від Ctrl+F, який скидається.
Запуск: подвійний клік по visual-tests.bat у корені проєкту (або відкрийте цей файл напряму).
На сцені працює мок FreePBX: коли розширення клікає #send, перехоплюємо та пишемо відповідь у pre[2], як на справжньому FreePBX.
